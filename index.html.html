Q2. Demonstrate Minimax Search with an example.

1. Introduction

Minimax is an AI search algorithm used in two-player games. It helps select the best move by considering the

opponent's possible moves. MAX tries to get the highest score, while MIN tries to get the lowest score.

2. Main Concepts

MAX Player

Tries to maximize the score.

Selects the largest available value.

Represents the player trying to win.

MIN Player

Tries to minimize the score.

Selects the smallest available value.

Represents the opponent.

Game Tree

Shows possible moves in a game.

Contains branches for different choices.

Helps evaluate possible results.

4. Working

Create a tree of possible game moves.

Assign scores to the final states.

MIN selects the smaller values: 3 and 2.

MAX selects the higher value, so the answer is 3.

5. Example

In a game, MAX has two possible moves. The first has a minimum score of 3, and the second has a minimum score

of 2. MAX selects the first move because 3 is greater than 2.

6. Advantages

Helps choose the best move.

Considers opponent moves.

Useful for strategic games.

Provides optimal decisions with a correct game tree.

Can use alpha-beta pruning.

7. Disadvantages

Requires high computation.

Large game trees are difficult to search.

Depends on evaluation scores.

Can be slow for complex games.

Not suitable for every problem.

8. Applications

Chess

Tic-tac-toe

Checkers

Board games

Game-playing AI

Q. No. 3 – Search and Knowledge Representation

Q7. Demonstrate Heuristic Search Techniques with an example.

1. Introduction

Heuristic Search is an AI technique that uses estimates to find a solution faster. A heuristic function h(n) estimates

the remaining cost from the current state to the goal.

2. Types of Heuristic Search

Greedy Best-First Search

Selects the node with the lowest heuristic value.

Tries to reach the goal quickly.

Example: Exploring the city estimated to be nearest to the destination.

A Search*

Uses both the cost already travelled and the estimated remaining cost.

Formula: f(n) = g(n) + h(n).

Example: Finding a least-cost route.

Hill Climbing

Moves toward a better neighboring state.

Repeats until no better neighbor is found.

Example: Improving a timetable to reduce clashes.

Beam Search

Keeps only a limited number of promising choices.

Removes less promising choices at each level.

Example: Finding likely sentence completions.

4. Working

Start from the initial state.

Calculate the heuristic value of possible nodes.

Select the most promising node using the chosen technique.

Repeat until the goal is reached.

5. Example

A navigation system estimates the remaining distance to a destination. Greedy search chooses the node with the

lowest estimated distance, while A* considers both the distance travelled and the estimated distance remaining.

6. Advantages

Reduces search time in many problems.

Explores promising paths first.

Useful for large search spaces.

A* can find an optimal path under suitable conditions.

Helps solve complex problems.

7. Disadvantages

Depends on the quality of estimates.

Some methods may miss the best solution.

A* can use a lot of memory.

Poor estimates waste time.

Hill climbing may get stuck in local optima.

8. Applications

Route planning

Game playing

Robot navigation

Puzzle solving

Scheduling

Q8. Demonstrate Generate-and-Test with appropriate examples.

1. Introduction

Generate-and-Test is a simple AI problem-solving technique. It generates a possible solution and checks whether it

satisfies the required conditions. If it fails, another solution is generated.

2. Main Steps

Generate

Produces a possible solution.

Can generate different answers.

Example: Trying a number.

Test

Checks whether the answer is correct.

Compares it with the required conditions.

Rejects answers that fail.

Accept

Accepts a solution that satisfies all conditions.

Stops searching if one solution is enough.

Returns the correct answer.

Repeat

Generates another solution if the previous one fails.

Continues testing new possibilities.

Stops when a solution is found or the search ends.

4. Working

Define the problem and conditions.

Generate a possible answer.

Test whether it satisfies the conditions.

Accept it if correct; otherwise, repeat.

5. Example

Find a number between 1 and 10 divisible by both 2 and 3.

Generate 4: Reject because it is not divisible by 3.

Generate 6: Accept because it is divisible by both.

The answer is 6.

6. Advantages

Easy to understand.

Simple to implement.

Suitable for small problems.

Can find a solution when all possibilities are tested.

Does not require complex reasoning.

7. Disadvantages

Can be slow for large problems.

Generates incorrect solutions.

Uses time and computing resources.

Requires correct testing conditions.

May not finish for an unlimited search space.

8. Applications

Puzzle solving

Mathematical problems

Simple scheduling

Game moves

Testing possible combinations

Q14. Explain Bayes' Theorem with an appropriate example.

1. Introduction

Bayes' Theorem calculates the probability of an event using prior information and new evidence. It helps update

our understanding when new information becomes available.

Main Terms

Prior Probability

Represents the probability before new evidence.

Uses previously available information.

Example: The percentage of people who have a disease.

Likelihood

Represents the probability of observing evidence when an event is true.

Measures how well the evidence fits the event.

Example: The chance of a positive test in a person with the disease.

Evidence

Represents the information that has been observed.

May support more than one possible explanation.

Example: Receiving a positive test result.

Posterior Probability

Represents the updated probability after observing evidence.

Combines prior probability and likelihood.

Helps estimate how likely the event is now.

3. Formula

P(A | B) = [ P(B | A) × P(A) ] / P(B)

5. Working

Find the prior probability.

Calculate the likelihood of the evidence.

Find the total probability of the evidence.

Apply Bayes' formula to calculate the updated probability.

6. Example

Suppose 1% of people have a disease. A test detects 90% of people who have it, and 5% of people without the

disease receive a false-positive result.

P(D | +) = [ 0.90 (0.01) ] / [ 0.90 (0.01) + 0.05 (0.99) ]

= 0.009 / 0.0585 ≈ 15.4%

Therefore, the probability of having the disease after a positive result is approximately 15.4%, under these

assumptions.

7. Advantages

Updates probabilities with new evidence.

Helps decision-making.

Uses prior knowledge.

Supports predictions.

Handles uncertainty mathematically.

8. Disadvantages

Requires probability estimates.

Incorrect assumptions affect results.

Complex calculations may be difficult.

Poor evidence produces unreliable results.

Does not guarantee a correct decision.

9. Applications

Medical testing

Spam filtering

Weather forecasting

Fraud detection

Risk analysis

Q15. Demonstrate Probability with an example.

1. Introduction

Probability measures how likely an event is to happen. Its value ranges from 0 to 1, where 0 means impossible

and 1 means certain.

2. Types of Probability

Theoretical Probability

Uses possible outcomes to calculate probability.

Assumes outcomes are equally likely.

Example: Getting heads on a fair coin.

Experimental Probability

Uses actual results from repeated experiments.

Calculated using observed frequencies.

Example: Counting heads in 100 coin tosses.

Conditional Probability

Calculates the probability of an event given another event.

Uses information about a known condition.

Example: Probability of rain given cloudy weather.

Joint Probability

Calculates the probability that two events happen together.

Considers both events at the same time.

Example: Probability of drawing a red card and an ace.

3. Formula

P(E) = Favourable Outcomes / Total Outcomes

5. Working

Identify the experiment and event.

Count all possible outcomes.

Count the favourable outcomes.

Divide favourable outcomes by total outcomes.

6. Example

A fair coin has two possible outcomes: heads and tails.

P(Heads) = 1/2 = 0.5 = 50%

Therefore, the probability of getting heads is 50%.

7. Advantages

Measures uncertainty.

Supports decision-making.

Helps predict possible outcomes.

Supports statistical analysis.

Helps assess risk.

8. Disadvantages

Does not guarantee an outcome.

Depends on assumptions.

Real-world probabilities may be difficult to calculate.

Limited data can produce unreliable estimates.

Can be misunderstood.

9. Applications

Weather forecasting

Medical research

Insurance

Games

Machine learning

Business risk analysis
